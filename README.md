# Pokédex Collection — AR/SIR

Site statique gratuit pour suivre une collection Pokémon.

## Contenu
- 1028 Pokémon de base avec l'ordre personnalisé du classeur.
- 183 formes/variantes supplémentaires : 57 régionales, 74 Méga, 32 Gigamax, 20 variantes TCG.
- Recherche instantanée, filtres, cases Possédé, statut, carte/extension et notes.
- Sauvegarde locale dans le navigateur.
- Export/import JSON pour faire une sauvegarde ou transférer la collection.

## Mise en ligne gratuite avec GitHub Pages
GitHub Pages peut publier des fichiers HTML/CSS/JS depuis un dépôt GitHub. Avec GitHub Free, un dépôt public peut être utilisé pour Pages.

1. Crée un nouveau dépôt GitHub public.
2. Mets `index.html` et `.nojekyll` à la racine du dépôt.
3. Dans **Settings → Pages**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`.
4. GitHub publiera ensuite le site à l'adresse du dépôt.

Le site ne contient aucun serveur ni compte utilisateur : les modifications restent dans le navigateur utilisé.
